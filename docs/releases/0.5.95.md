# Kuvo Code 0.5.95 — the terminal, reliable

- **The terminal opens every time.** Two page bugs made it fail at the first or second
  visit: the container was marked ready once and never cleared, so hiding the panel or
  choosing Files/Changes came back to a dead socket; and addon-fit's browser build was
  read as a class when it is a namespace, which threw before the terminal was drawn. The
  page now keeps the terminal's own handle, reads `FitAddon.FitAddon`, and fits the grid
  when it is actually visible — on the first open, when the panel is resized, and when
  the terminal comes back from another tab.
- **The shell survives the panel.** Hiding the panel or switching to Files/Changes no
  longer ends the ConPTY. The same shell is there when the terminal returns, as the Mac's
  terminal tab is. Only the shell exiting, the page reloading, the project restarting, or
  the app closing ends it.
- **The shell starts where the project is, at the size the page drew.** The page opens
  the socket with the project folder and its real `cols`/`rows`; the server starts
  PowerShell there instead of in the home folder at 80×24. The first prompt is no longer
  wrapped by a grid that is resized later. Windows PowerShell is the guaranteed shell,
  with PowerShell 7 when it is installed.
- **A dead shell can be restarted.** The terminal says why it closed — the shell's exit,
  or the reason the server could not start one — and offers a drawn *Restart Terminal*
  button in the note and in the panel header. *New Terminal* restarts a dead shell.
- **Run interrupts what is running first.** The Mac's Run sends Ctrl-C, waits 300 ms, then
  types the command (`TerminalSession.swift:56-63`); Windows did neither and typed the
  command into whatever was still running. It now matches, after changing to the
  project's folder.
- **The terminal has the Mac's right-click menu.** *Add to Message* sends the selected
  output to the composer in a code block with trailing spaces removed, *Copy* copies the
  selection, and *Paste* types the clipboard into the shell. The menu closes with Escape,
  as a Mac menu does, and the caret goes back to the shell.

The terminal is now tested through the real road, not only the page's data. A new test on
the Windows runner starts `node-pty`, connects over `ws`, proves the shell starts in the
chosen folder, answers, takes a resize, exits, and starts a second shell; it runs before
electron-builder rebuilds the native module for Electron's ABI. 316 unit tests pass — 256
in the port, 41 in the harness, 19 in the link bridge — with `tsc --noEmit` clean, lint
showing only the existing declaration warnings, the page built, and the live engine turn
and the page against the real engine passing in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
