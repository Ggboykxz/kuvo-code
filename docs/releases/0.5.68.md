# Kuvo Code 0.5.68 — the lines a call added and removed

- **The tool rows show the lines the call changed** — `+12 −3` after the row's words, where
  the Mac prints them (`ToolCallView.swift:106-107`), in the system's green and red
  (`Theme.swift:35-36`), at the caption's size in the medium weight with monospaced digits,
  four points between the two (`Theme.swift:147-156`).
- **The numbers come from where the Mac reads them**: the engine keeps the files a call
  changed in the call's own metadata, and the transcript now carries that metadata — from
  the messages the engine stored and from the events of a live call — because that is the
  only place the Mac reads it from (`ToolCallView.swift:358-366`,
  `SessionEdits.swift:19-22`, `OpenCodeKit/Events/Transcript.swift:422`). A check holds the
  read, the row, and the colours to those places.

real engine passes in Chromium.
