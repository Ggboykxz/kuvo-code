# Kuvo Code 0.5.98 — New Project and New Chat

- **New Project…** and **New Chat** are in the File menu now, with the Mac's keys
  (⇧⌘N and ⌥⌘N). *New Project…* opens the folder picker the way the Mac's *New Project…*
  opens its editor; *New Chat* starts a session, the way the Mac starts one in its Chats
  folder.

`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
