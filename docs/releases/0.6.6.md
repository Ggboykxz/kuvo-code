# Kuvo Code 0.6.6 — smoother panel and focus

- **Panel tabs fade in** when they come into view, so switching between Files, Changes
  and Terminal reads as a change of place rather than a snap. Reduced motion stops it.
- **Focus follows the panel**: opening it puts the caret in the terminal, or the search
  field when Files is in view.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
