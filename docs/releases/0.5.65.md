# Kuvo Code 0.5.65 — the mark draws itself, the way the Mac's does

- **The upstream's `main` is merged into the Windows branch** — 715 commits of it, including
  the refactor of the KuvoLink bridge. Our Windows changes to the bridge are re-applied on
  top of their new shape: the command line a process tells on Windows (the process list,
  where there is no `/proc`), the bridge's own `isBridge` and `bridgeSpawnOptions`, and the
  pid file that has to go when Windows gives no `SIGTERM`. The pull request is mergeable
  again.
- **The bridge's own test now knows that Windows has no POSIX file modes**: the key's file
  is 600 where the system has such modes; on Windows it is the profile folder's own
  permissions that keep the key there.
- **The press is the Mac's press**: a control that is pressed is filled, not squeezed — the
  scale the old direction had is gone from the stylesheet.
- **The engine's events reach the conversation.** The page was listening for event names the
  engine never sends (`message.part.updated`), so the words of a reply and the end of a turn
  never arrived: the reply appeared only when the page was reloaded, and the Stop button
  stayed. The names are the engine's own now (`session.text.delta`,
  `session.execution.succeeded`), the same ones the Mac's transcript uses.
- **A run ends when the engine says so.** The measure of "the agent is at work" takes both
  halves of the Mac's own: the conversation's last words are unfinished *and* the engine still
  has the session among the active ones (`SessionModel.swift:573-587`).
- **The working mark is the Mac's own mark, at the Mac's weight.** The app's prompt mark
  painted a stroke of 0.019 pt where the Mac's is 1.21 pt — the mark in the tab was a
  hairline. The icon's own proportions are the mark's now, and the mark draws itself in
  short dashes over a faint copy of itself, as the Mac's spinner does
  (`Spinner.swift:1-177`): the chevron first, the cursor next, a hold, and a fade, over the
  Mac's 1.6 s round.

- **The mark fades as a whole**, the Mac's way: the layer that holds both the faint copy
  and the drawn one fades, so the faint one fades with it (`Spinner.swift:141-143`).
- **The mark is the spinner's now** — the tab's badge draws the prompt mark in dashes, and
  the mark's own component is gone from the symbols, where the Mac keeps it in the spinner.

190 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against the
real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
