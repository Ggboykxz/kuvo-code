# Kuvo Code 0.5.93 — the panel's tree is the project's

- **The panel's file tree is rooted at the project's own folder**, as the Mac's is
  (`FilesView.swift:250-275`). The project's folder and the files' paths were compared as
  they came — one with the platform's separator, the other with a slash — so on Windows
  the tree's root was the whole drive, and the project's files were buried under it. Both
  are read with one separator now: the project's folder is the root, and the files sit in
  it, as they do on the Mac.

This release also carries **0.5.91's numbered file view** (`CodeTextView.swift:119-168`)
and **0.5.92's Add to Message** (`CodeTextView.swift:91-111`, `FilesView.swift:389-392`):
their Windows runs stopped at the tree's root, and nothing else in them changed.

294 unit tests pass — the tree on both kinds of path, the ruler, and the message the menu
writes, proved without a browser — `tsc --noEmit` is clean, the page builds, and the live
page against the real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
