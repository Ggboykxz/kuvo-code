# Kuvo Code 0.5.75 — the window remembers its own state

- **The panes' widths are kept.** The sessions' width, the panel's and the split's — the
  Mac keeps them between windows (`MainView.swift:38-40`, `90`), and so does this client
  now: a pane dragged to a width is opened at that width next time.
- **What is folded away is kept.** The sections the user folded, and the projects they
  folded, are as they were left (`SidebarView.swift:32-34`).
- **The row at the top can be put away**, as the Mac's General settings say: *Show the tab
  bar* (`GeneralSettings.swift:23`). With it away, the project, its branch and the sessions
  as tabs go, and the window's own buttons stay.

clean, the page builds, and the live page against the real engine passes in Chromium,
twice.
