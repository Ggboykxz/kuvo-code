# Kuvo Code 0.5.99 — the terminal takes the card's colour

- **The terminal is part of the card now.** Its background is the card's own fill and its
  text the card's ink, light on dark and dark on light, with the Mac's ANSI palette for
  each (TerminalSession.swift:108-124). The colours follow the appearance picker and the
  system theme, so a light window no longer carries a black box.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
