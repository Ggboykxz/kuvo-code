# Kuvo Code 0.5.89 — the conversation shows the comments back

- **A message that carried comments is taken apart when it is shown**
  (`AgentReferences.swift:170-179`): the words are the user's own, and each comment is a
  card of its own above them.
- **The card is the Mac's** (`ChangesPanel.swift:1123-1155`): the place it points to, with
  the Mac's mark beside it, the line it was written on with its own coloured bar, and what
  it says. The `text.bubble` mark is drawn for the place.

277 unit tests pass — the rules that read a message apart, proved without a browser —
`tsc --noEmit` is clean, the page builds, and the live page against the real engine passes
in Chromium.

The live tests ask a free model that can answer — the public free models can refuse for a
while, and the build no longer fails on the provider's mood — and the Windows build is
stopped rather than left to wait for ever, so a release is never made from a run that did
not finish.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
