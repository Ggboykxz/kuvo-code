# Kuvo Code 0.5.61 — a real menu bar, and the last of the small ones

- **The shell has a real menu bar** (NativeMenu.swift:5-165): the app's own menu, File, Edit,
  View, Window and Help, with the Mac's items and the keys beside them. The items that act on
  the conversation — New Session, Open Folder…, Export Conversation as Markdown, Command
  Palette, Settings…, Show Panel, Show Sessions — ask the page to do it, by the shortcut the
  Mac uses.
- **The code block's copy button wears the Mac's mark** (CodeBlockStyle.swift): the copy
  mark, which becomes a check when the text is copied.
- **A double-click on the title bar zooms the window**, as it does on the Mac
  (Card.swift:186-198) — on Windows, that is the window maximised.

184 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against
the real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
