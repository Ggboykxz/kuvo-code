# Kuvo Code 0.5.56 — the update finds you, even while the app is open

The automatic update, made to keep looking.

- The shell asked GitHub for a newer release **when it started** — and only then, so a version
  published while the app sat open went unnoticed until the next launch. It asks again every
  six hours now, quietly: a note in the corner, not a question that waits for an answer.
- Clicking that note asks the question: "Kuvo Code 0.5.56 is available. Download it now?",
  and the installer that goes with it is downloaded and run — the same one the releases
  carry, which replaces what is installed.

Nothing else changed: the check still reads our own releases (they are prereleases with a tag
of their own, `windows-v0.5.56`, which electron-updater's GitHub provider does not see), still
compares the three numbers of the version, and still offers the installer.

174 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against the
real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run — and on an update that came the same way.
