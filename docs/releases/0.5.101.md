# Kuvo Code 0.5.101 — Browser, Passwords, Phone, Auto and Machines settings

- **Browser page** (`BrowserSettings.swift`): search engine, browsing history, website
  data.
- **Passwords page** (`PasswordsSettings.swift`): offering to save passwords, kept in
  the system's credential store.
- **Phone page** (`PhoneSettings.swift`): pairing Kuvo Code for iPhone with this Mac.
- **Auto page** (`AutoSettings.swift`): your lists of models, one for bugfixes and one
  for features; runs with the coding agents, which aren't available on this client yet.
- **Machines page** (`MachinesSettings.swift`): Linux servers whose engine Kuvo Code
  runs over SSH.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
