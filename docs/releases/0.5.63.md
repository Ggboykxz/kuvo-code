# Kuvo Code 0.5.63 — the providers' marks

- **The model menu wears each provider's mark** (`ProviderLogo.swift`): the maker's own
  mark, fetched once from models.opencode.ai — the same place the Mac fetches it from —
  and drawn in the ink, or in the maker's colour where it has one. Until a mark arrives,
  the provider's initial stands in for it, at 55 % of the size, semibold and rounded, the
  Mac's own fallback.

188 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against
the real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
