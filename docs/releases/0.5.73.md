# Kuvo Code 0.5.73 — a session's own menu, and the sessions kept at the top

- **A session's row takes the Mac's menu, in the Mac's order, in the Mac's words**
  (`SidebarView.swift:600-643`): *Pin* or *Unpin*, *Open Beside*, *Rename…*, *Show in
  Folder*, *Copy as Markdown*, *Export as Markdown…*, *Archive* or *Unarchive*, and
  *Delete…* — the last one red, and asking first, as the Mac's does. A menu carries what a
  menu carries: a line between the groups, an item that cannot be chosen, and the one that
  undoes.
- **A pinned session sits at the top of the sidebar**, in a *Pinned* section of its own, out
  of the recents (`SidebarView.swift:115-121`, `513-515`). The mark is the Mac's own
  (`kuvo.pinned`), written with the session's own metadata, so a session that is both pinned
  and archived keeps both (`Workspace.swift:342-364`).
- **The conversation is written out the Mac's way** (`ConversationExport.swift:9-69`): the
  title over it, "You" and "Agent" as the speakers, the agent's steps listed together until
  it says something — for any session, not only the one in view, and with what an undo took
  back left out.
- **"Show in Folder" opens the folder where the user can see it** — the Mac's *Show in
  Finder* is the Explorer here, and says so.

221 unit tests pass — the menu's order and words, the pin's mark, and the Markdown's shape
proved without an engine — `tsc --noEmit` is clean, the page builds, and the live page
against the real engine passes in Chromium, twice.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
