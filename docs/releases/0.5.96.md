# Kuvo Code 0.5.96 — Notifications, Privacy and Panel settings

- **Notifications settings** (`GeneralSettings.swift:166-194`): the sessions toggle, a sound
  with each notification, the count on the taskbar icon, and a button that opens the
  system's notification settings. The values stay on this machine.
- **Privacy settings** (`GeneralSettings.swift:203-230`): sharing anonymous usage, what is
  sent, and the link to the privacy page; plus the shortcuts to storage, the panel's
  browser and the saved passwords.
- **Panel settings** (`BrowserSettings.swift:5-30`): what the panel starts with, whether
  it shows itself when the agent browses, tidying the agents' tabs, and the new tab
  page — tools and suggested sites with their count.

The Mac's pages are drawn with the same words and the same toggles; the Windows client
keeps the values in its own store, since it has no dock and no Keychain to ask.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
