# 0.7.0 — honest surfaces, measured colour

0.7.0 is a foundation release for the Windows client. It splits the large files,
hardens the shell's edges, and makes every Settings page say what the Windows
client can actually do. It does not add the panel's browser, the phone link, or
sessions on remote machines.

## What changed

### Smaller modules

- `server.mjs` 1570 → 373 lines; `routes.mjs` is a dispatcher over eight route
  modules (`projects`, `files`, `git`, `sessions`, `models`, `settings`, `bots`,
  `machines`).
- `Settings.tsx` 2070 → 200 lines, with the pages in `SettingsPages.tsx`,
  `SettingsPagesExtra.tsx`, `SettingsAgents.tsx` and `SettingsMcp.tsx`.
- `App.tsx` 2666 → 397 lines, with the conversation, composer, sidebar,
  overlays and settings in their own files.

### Security

- The filesystem is contained: with no project open, the home folder is the
  floor, and `kuvo:show-in-folder` checks existence and containment.
- `kuvo:open-external` accepts only `http:` and `https:`.
- The page's CSP drops `unsafe-eval` and limits `connect-src` to the harness and
  its WebSocket.
- The sanitizer drops `style`, `srcset`, `form`, `svg` and `math`, and refuses
  `data:` and `vbscript:` URLs.
- Git paths reject `..` and absolute paths; the installer filename is validated
  and written as a stream.
- The harness rejects cross-origin browser requests to its localhost API.

### Settings that tell the truth

- **Bots** lists the bots that live on this computer, read from their own folders
  under `~/.kuvo-code/bots`. Making and changing a bot stays the Mac's job,
  because only the Mac writes a bot's kit and instructions.
- **Machines** keeps the list in `~/.kuvo-code/machines.json`, rejects a
  destination that isn't `user@host`, and asks the machine's own `ssh` whether it
  gets in. Installing the engine and running sessions there are not wired yet.
- **Browser**, **Passwords**, **Phone**, **Notifications** and **Panel** say they
  are not part of the Windows client yet instead of keeping switches nothing
  reads. **Passwords** will use Windows Credential Manager when the browser
  arrives, never `localStorage`.
- **Auto** reports the coding agents found on this computer. Running a session
  through them is not wired yet, so the page says that rather than offering them
  as modes.

### Colour, measured where it lives

`windows/tools/contrast-check.mjs` reads the tokens from
`windows/harness/ui/style.css`, follows the cascade to the values the page
actually renders, composites alpha inks over their surfaces, and measures the
light, narrow-window and dark palettes. All 87 ink/surface pairs now read at
WCAG 2.1 AA (4.5:1 or better), and the check runs inside
`node windows/tools/verify.mjs`.

The effective palette changed to get there: accent `#0062CC` (hover `#0051A8`),
success `#1E7B34`, warn `#9A5B00`, danger `#C4271E`, and the faint ink at 62 %
light / 50 % dark. Dark accent is `#2F97FF`. `docs/DESIGN.md` matches.

### Interface

- Interactive targets are at least 44 px.
- At 760 px and narrower the sidebar becomes an off-canvas drawer with an
  overlay, and the Settings sidebar gets the same treatment.
- The reduced-motion rule is valid CSS again: it stops the thinking shimmer and
  the pulse instead of dropping the whole rule.

### CI fixes

Three failures that had been called environmental were real code problems, now
fixed:

- `routes/bots.mjs` imported `kuvo-link.js` across the repository, which esbuild
  could not resolve when building the single-file harness executable. The route
  reads the bot folders directly instead.
- A reduced-motion selector list contained `@keyframes` rules, which made the
  whole rule invalid. The class that wears the animation stops instead.
- A bridge test read `/proc/<pid>/cmdline` before the freshly spawned process had
  written it. The shared helper now waits for a stdout handshake.

## Tests

- 256/256 port tests
- 43/43 harness tests
- 68/68 link bridge tests
- 6/6 SSH check tests
- `node windows/tools/verify.mjs`: tests, contrast, lint, typecheck and page
  build all green locally.

The Windows CI run on the release tag is the gate for the assets below.

## Not in this release

- The panel's browser and its settings; saved passwords.
- The phone link.
- Notifications and the Mac's side-panel preferences.
- Running sessions through Claude Code, Codex, Cursor, Grok or Antigravity.
- Installing the engine on a machine and running sessions there.
- Creating and editing bots on Windows.

These are tracked in `docs/ROADMAP.md`.
