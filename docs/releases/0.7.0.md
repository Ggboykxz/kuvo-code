# 0.7.0 — Windows client foundation complete

This release completes the 0.7.x foundation: every Settings page now talks to the harness, the filesystem is properly contained, and the app meets WCAG 2.1 AA contrast.

## What's new

### Bots (complete)
- Richer editor: name, job/personality, model (provider/model), look (color/shape/face)
- Stored on this machine via `kuvo-link.js`; listed in `kuvo/bots`
- Wake-ups, group chats, sub-agents and @-mentions scaffolded

### Machines (complete)
- Add machine by name + SSH destination (`user@host`)
- Test reachability from Settings → Machines
- Install the engine on the remote over SSH
- Sessions can be routed to the machine (via agents bridge)

### Auto rail
- Coding agents (Claude Code, Codex, Cursor, Grok, Antigravity) detected via `/api/agents/detect`
- Detected agents appear in the model picker with their own logo
- Selecting one routes the session through the agents bridge (`kuvo-agents.js`)

### Passwords
- Windows Credential Manager integration (`cmdkey` / `New-StoredCredential`)
- Harness API: `/api/credentials` (list, get, store, delete)
- Secrets never touch `localStorage` or the app's JS context

### Browser Settings
- Search engine (Google/Bing/DuckDuckGo) persisted via harness
- Browsing history count + clear
- Website data (cookies/sign-ins) clear via harness
- Stored in `~/.kuvo-code/browser/`, not `localStorage`

### Security hardening
- Filesystem containment: home folder is the floor when no project is open
- `kuvo:open-external` only accepts `http:`/`https:`
- `kuvo:show-in-folder` validates existence and home-folder containment
- CSP: removed `unsafe-eval`, `connect-src` locked to localhost
- Sanitizer drops `style`, `srcset`, `form`, `svg`, `math` + blocks `data:`/`vbscript:` in URLs
- Git path guards block `..` and absolute paths
- Origin check on harness API
- Installer filename validation + streaming write

### Accessibility / Contrast (WCAG 2.1 AA)
- Accent: `oklch(56% 0.18 255)` — 4.6:1 on white
- Warn: `oklch(56% 0.18 85)` — 4.6:1 on white
- Success: `oklch(54% 0.18 140)` — 4.6:1 on white
- Danger: `oklch(55% 0.22 25)` — 5.3:1 on white
- Static contrast checker: `windows/tools/contrast-check.mjs`

### Mobile responsive
- Sidebar → off-canvas drawer (≤760px) with overlay
- Settings sidebar same treatment
- All interactive elements ≥44px touch targets
- `touch-action` on drag handles

- `App.tsx` 2666 → 397 + 5 modules
- `routes.mjs` 1237 → 25 + 7 domain modules
