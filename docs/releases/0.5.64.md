# Kuvo Code 0.5.64 — the upstream's main, merged in

- **The upstream's `main` is merged into the Windows branch** — 715 commits of it, including
  the refactor of the KuvoLink bridge. Our Windows changes to the bridge are re-applied on
  top of their new shape: the command line a process tells on Windows (the process list,
  where there is no `/proc`), the bridge's own `isBridge` and `bridgeSpawnOptions`, and the
  pid file that has to go when Windows gives no `SIGTERM`. The pull request is mergeable
  again.
- **The bridge's own test now knows that Windows has no POSIX file modes**: the key's file
  is 600 where the system has such modes; on Windows it is the profile folder's own
  permissions that keep the key there.
- **The press is the Mac's press**: a control that is pressed is filled, not squeezed — the
  scale the old direction had is gone from the stylesheet.

190 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against the
real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
