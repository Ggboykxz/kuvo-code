# 0.7.2 — find marks every match, and ask in place

0.7.2 is the second polish release for the Windows client. It makes Find see
every match on both sides of the conversation, replaces the last system
confirm dialogs with inline confirmations, and adds the next layer of
micro-interactions. It still does not add the panel's browser, the phone link,
sessions on remote machines, or running sessions through coding agents.

## What changed

### Find marks everything it counts

- The conversation is marked on both sides: assistant replies and your own
  messages, and the messages waiting to go. Before, a match on your words was
  never marked, and a long reply's mark stopped at the first one in each text
  node.
- The mark you are on takes the accent, with a short ring drawing in; the
  others keep the warn wash. The arrows step the marks themselves, so a reply
  with several matches scrolls to the exact one the count says you are on,
  not just to the message.
- The bar slides down over the card when it opens, the count pops when it
  changes (and is read aloud by a screen reader), and the arrows nudge toward
  the direction they step; Done turns as it is reached for.
- The sidebar's search results mark the matched words in each snippet.

### Native confirm dialogs are gone

- Revert a file in Changes, remove an MCP server, agent, skill or command, and
  delete an archived session for good: all ask in the row itself now, the way
  deleting a session does. **Keep** takes the focus first, so Return never
  destroys anything; **Revert**, **Remove** or **Delete** is the second choice;
  Escape or moving the focus away leaves things as they were, and focus returns
  to the button you came from.
- The `confirm()` dialog is gone from the app entirely.

### More micro-interactions

- A toast shows its time left as a line under it that runs out over the
  5.2 s; it stops while the stack is held open, as the timer does. Errors draw
  it in the danger colour.
- The file tree's rows fade in as folders open, folder chevrons turn a beat
  when reached for, and file marks brighten.
- Attachments pop in when attached; a chip's remove button turns as it is
  reached for.
- The queue dock opens with its items following in order; a quote card rises in
  over the composer; a file's diff fades in when it opens and its comment
  bubble scales in, lifts, and deepens under the hand.
- Search results arrive in a short stagger. The appearance thumbnails lift
  under the pointer, and the chosen one gains the accent's glow.
- The empty conversation rises in when a session opens.

### Motion: Reduced

- The new moves stop with the setting and the system's: the toast countdown
  line hides, the mode thumbnails do not lift, and the find marks keep the
  plain wash without the ring.

## Tests

- New `windows/find.test.mjs`: every occurrence is found in order, case is
  folded, adjacent matches do not overlap, queries shorter than two characters
  find nothing, and the count is the number of ranges — the same ranges that
  make the marks.
- 262/262 port tests, 43/43 harness tests, 68/68 link bridge tests, 6/6 SSH
  check tests.
- `node windows/tools/verify.mjs`: tests, contrast, lint, typecheck and page
  build all green locally.

The Windows CI run on the release tag is the gate for the assets below.

## Not in this release

- The panel's browser and its settings; saved passwords.
- The phone link.
- Notifications and the Mac's side-panel preferences.
- Running sessions through Claude Code, Codex, Cursor, Grok or Antigravity.
- Installing the engine on a machine and running sessions there.
- Creating and editing bots on Windows.

These are tracked in `docs/ROADMAP.md`.
