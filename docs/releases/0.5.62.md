# Kuvo Code 0.5.62 — every project in the sidebar, and a real menu bar

- **The sidebar holds every project**, the way the Mac's does (`SidebarView.swift:178-196`):
  a *Projects* heading that folds away, every project with its drawn folder, its name and a
  compose button — a new session in that project — and its own sessions: five to a project,
  the rest on request (`SidebarView.swift:62-63`), with the sessions' titles lined up with
  the project names above them. Below them, the *Recents*: the eight most recent sessions
  across the projects (`SidebarView.swift:490-493`).
- **A project can be opened from the sidebar**: the harness serves any folder it is asked for
  (`POST /api/project`), the engine already lists the sessions of any directory, and the
  shell and the harness now keep **one** list of recent projects — the same file — so the
  tray's menu and the sidebar are one list.
- **The shell has a real menu bar** (`NativeMenu.swift:5-165`): the app's own menu, File,
  Edit, View, Window and Help, with the Mac's items and the keys beside them. The items that
  act on the conversation ask the page to do it, by the shortcut the Mac uses.
- **A double-click on the title bar zooms the window**, as it does on the Mac
  (`Card.swift:186-198`) — on Windows, that is the window maximised.
- **The code block's copy button wears the Mac's mark** (`CodeBlockStyle.swift`): the copy
  mark, which becomes a check when the text is copied.

186 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against the
real engine passes in Chromium. The capture matrix in `docs/captures/` is regenerated.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
