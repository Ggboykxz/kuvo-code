# Kuvo Code 0.5.88 — a comment on a line is the Mac's own

- **The editor is the Mac's** (`ChangesPanel.swift:1157-1212`): *Add a comment…* under the
  line, Escape cancels, Ctrl+Return saves, and the button says *Comment*.
- **The comment is kept as a card under its line** (`ChangesPanel.swift:1088-1121`): the
  user, the line it is on (*Comment on line R12*), and a way to take it away (*Delete*). It
  stays with the line it was written on, by its number and by its text, so it does not
  slide onto another line when the file changes (`ChangesPanel.swift:873-880`).
- **The comments go to the agent in the Mac's own block**, with the words you wrote in
  front of it (`ReviewComments.swift:21-39`).
