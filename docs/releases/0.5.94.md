# Kuvo Code 0.5.94 — the menu bar's own commands, and Open Quickly

- **The menu bar carries the Mac's command groups** (`KuvoCodeApp.swift:130-229`): the
  app menu's *Settings…*; File's *Open Quickly…*, *Close Tab*, *Close Window* and
  *Reopen Closed Tab*; Edit's *Find in Conversation…*; the **Session** menu with *Stop*,
  *Build Mode* and *Plan Mode*; the **Tools** menu with *Show Changes*, *Show Files*,
  *Run*, *New Terminal* and *Show Panel*; and View's tab commands, *Show Tab* submenu and
  *Appearance* picker. Help now points where the Mac's does — the docs, the release notes,
  the issue page and the contact address.
- **A closed tab is remembered where it was, and comes back from the menu**
  (`MainView.swift:1150-1232`). The last fifty closed tabs are kept; *Reopen Closed Tab*
  puts the last one back at its original index, skipping the tabs opened again in the
  meantime and the sessions deleted since. Closing the tab in view shows the tab that took
  its place — the next one, or the last one — as the Mac does. *Show Next Tab*,
  *Show Previous Tab* and *Show Tab* (`Ctrl+1`–`Ctrl+8`, `Ctrl+9` for the last) walk the
  strip.
- **Open Quickly is the Mac's own palette** (`OpenQuickly.swift:4-104`): a 560-point card,
  80 points from the top, with a 48-point search, 30-point rows and ten matches at most.
  Before anything is typed it offers the project's files newest first
  (`ProjectFiles.newestFirst`); after that it ranks the name itself, the start of the name,
  the name anywhere, then the path, with the Mac's tie-breaks. Choosing a file opens it in
  the side panel. The harness lists files by modification time for it
  (`/api/files?sort=recent&limit=…`); the mentions list still gets its own first forty.
- **The menu's words stay true.** The tab bar's command changes between *Hide Tab Bar* and
  *Show Tab Bar*, and the Appearance picker checks the theme in use, because the page
  tells the shell what changed.

A menu bar does not offer what the client cannot do: *New Project*, *New Chat*, the bot
commands, *New Browser Tab* and *Accounts* are not drawn. They are recorded in the port's
ledger, waiting for their surfaces, rather than shipped as dead items.

306 unit tests pass — the tab history, Open Quickly's ranking, the shortcuts and the menu
contracts proved without a browser — `tsc --noEmit` is clean, the page builds, and the live
page against the real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
