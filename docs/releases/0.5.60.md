Phase 8 of the Mac UI port: the pass that says what is true.

- **The ledger is brought up to date** (`docs/MAC-UI-MAP.md`): the rows that are now the
  Mac's are marked so — the drawn folder and the prompt mark, the hover language, the
  accent badge, the quote card, the popover that flips, the pane resizer, the prompt mark in
  the spinner, the macOS look, the settings' grouped form.

  has not reopened (Notifications, Privacy, Panel), a provider's plan usage (which needs the

  does that one).

  captures are taken with kept in the repository (`windows/tools/fonts.conf`) so the pictures
  are the same wherever they are made.
- The checks that hold the Mac's values in place run in CI: the static ones twice (once over
  the sources as they are, once with Windows' line endings), the live page in Chromium
  against the real engine, and the measured values against this ledger.

182 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against
the real engine passes in Chromium.
