# Kuvo Code 0.5.74 — a tab's own menu

- **A tab carries the Mac's menu, in the Mac's order, in the Mac's words**
  (`TitleBar.swift:214-231`): *Open Beside* for the tabs beside the one in view, *Rename…*,
  then the tabs to close — *Close Tab*, *Close Other Tabs* (dimmed when one tab is open, as
  the Mac's is) and *Close All Tabs*.
- **The name is written in the tab itself**, where the title was (`TitleBar.swift:170-200`),
  as on the Mac — and it is the session's own name, the same one the sidebar's row writes.

clean, the page builds, and the live page against the real engine passes in Chromium, twice.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
