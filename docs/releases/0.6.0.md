# Kuvo Code 0.6.0 — our own software

- **The Windows client stops tracking the Mac app.** The parity documents
  (`MAC-UI-MAP.md`, `PARITY.md`, `windows-port.md`) are frozen at 0.5.101 and kept as
  historical reference. From here on the Windows client is its own product: new work is
  tracked in `docs/ROADMAP.md` and judged on its own value, not on how closely it matches
  a macOS app.
- **What we keep.** Everything that works: the terminal (persistent ConPTY, project
  folder and real grid, restart, Run, the Mac's right-click menu), the settings (21
  pages), worktrees, New Project and New Chat, and the terminal that takes the card's
  colour. The engine (opencode) stays the backend.
- **What changes.** No more parity constraints on wording or layout, no `mac-tokens`
  gate on new screens, and a roadmap of our own. The next batches are provider-plan
  usage, the Auto rail, bots, accounts, machines and the rest, in our own order.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
