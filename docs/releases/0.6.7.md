# Kuvo Code 0.6.7 — project hygiene

- **Agent context.** `AGENTS.md` states how the repository is laid out, how to run
  it, and the rules a change must keep. `docs/CODEMAPS/` maps the architecture, the
  modules and the files, and `docs/token-optimization.md` says how to work in a
  repository this large without reading all of it.
- **One gate.** `node windows/tools/verify.mjs` runs the port tests, the harness
  tests, the link bridge, the SSH check, lint, typecheck and the page build, and
  stops at the first failure. `--no-build` skips the build; `coverage.mjs` turns on
  Node's coverage report.
- **Dependencies.** CI now audits the runtime dependencies of the page, the harness
  and the shell at high severity, and Dependabot watches their three lockfiles.
- **Dialogs.** Settings and the command palette announce themselves as dialogs,
  take focus when they open, keep Tab inside, and return focus to what opened them.
  The palette's rows are options, the settings navigation says which page is open,
  and the accent swatches have names.
- **SSH.** The Machines reachability check no longer blocks the shell: it runs
  `ssh` asynchronously and rejects an empty, option-like or shell-like destination
  before starting it.
- **Honest placeholders.** Accounts no longer offers a Connect button that did
  nothing; it points to Providers and says signing in from Accounts comes next.
  Machines says it tests reachability only. The roadmap says the same.
- **Security.** `SECURITY.md` describes the Windows client's surface and what is
  in scope for a report.

322 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge, 6
for the SSH check — with `tsc --noEmit` clean, lint showing only the existing
declaration warnings, the page built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
