# Kuvo Code 0.5.57 — the settings' pages carry the Mac's own symbols

Phase 4 of the Mac UI port: the symbols, for the pages that exist.

- **Each Settings page carries the Mac's mark for it** (SettingsView.swift:196-232) —
  Appearance's palette, General's gear, Keyboard's command, MCP Servers' puzzle, Agents'
  people, Skills' cap, Commands' slash, Projects' folder, Providers' person, Usage's gauge,
  Git's branch, Archived Sessions' box, Permissions' shield, Engine & Storage's chip — drawn
  in the app's one symbol library, on the 16 pt grid, with a 1.5 pt stroke, round caps and
  joins, in `currentColor`. They were ad-hoc drawings in the page; now they are the Mac's
  symbols, in one place, with the rest.

176 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against
the real engine passes in Chromium.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
