# 0.7.1 — the app answers the hand

0.7.1 is a polish release for the Windows client. It adds interface sounds, a
stack of notes, an inline delete confirmation, skeleton rows and a layer of
micro-interactions across the page. It does not add the panel's browser, the
phone link, sessions on remote machines, or running sessions through coding
agents.

## What changed

### Interface sounds

- **Settings › Appearance › Sound** has two choices: Off and Subtle. Off is the
  default.
- The cues are made with the Web Audio API — no files, no network, nothing to
  license. A send is a small step up; a finished run settles through three
  notes; a failure falls two; a copy is one quiet tick.
- The choice is kept in the shell's `config.json`, not only in `localStorage`,
  so it survives a profile reset. Picking Subtle plays the tick, so the setting
  says what it means before the first run finishes.
- Only the session in view (or the split) makes a sound when a run ends. A run
  finishing in a tab you are not looking at stays quiet.

### Notes in the corner

- At most three notes are kept, newest in front, with the two behind peeking out
  above it.
- Pointing at the stack or focusing it opens the notes into a list. A note
  leaves after 5.2 seconds, waits while the pointer is on it, and can be
  dismissed with its close button or a click.
- The same words twice in a row are one note, so a loop that fails every second
  does not fill the corner.
- Errors take the danger colour. The live region is on the note's text, so the
  close button is not announced with every message.

### Deleting a session

- Delete asks in the row itself: **Keep** takes the focus first, so Return does
  not delete, and **Delete** is the second choice. Escape or moving the focus
  away keeps the session. The native confirm dialog is gone.
- The row menu's **Delete…** opens the same confirmation.

### Lists on their way

- Bots, Machines, Accounts and Usage plans show skeleton rows instead of
  “Loading…”. The shimmer stops when motion is reduced.

### Micro-interactions

- Chrome-less controls answer with a fill, the Mac's Pressable way: 8 % under
  the pointer and 13 % while it is down, never a squeeze of the whole row.
- Marks lean toward what they do: copy nudges right, close turns, compose tilts,
  section actions grow, the sidebar's new-session mark lifts, chevrons follow
  the panel, attach tilts.
- The row in use grows a short accent bar: the palette, Open Quickly, the
  Settings navigation and the current session.
- A menu arrives as one piece and its items follow in a 14 ms run, capped at
  eight items.
- A Settings page pushes in four pixels. The search well deepens and its mark
  takes the accent. The primary action lifts a pixel and settles back under the
  hand.
- Links in Markdown underline from the left, the way a hand would draw them.
- A copy says **Copied** for a moment with the Mac's check, and a code block's
  copy mark turns green.
- The dot of a working session breathes. The chosen swatch's ring draws itself
  in.

### Reduced motion

- “Motion: Reduced” now sets `html[data-motion="reduced"]`, so the hard-coded
  loops — the working dot, the skeleton shimmer, the menu stagger — stop as well
  as the token-driven transitions.
- `--motion-standard` is defined at the Mac binding's root, so the existing
  reduced-motion exemption has a real duration instead of an undefined token.

### Test isolation

- The shell-settings harness test now runs against a temporary `APPDATA` folder
  with an empty `config.json`, so it no longer reads or writes the machine's
  real choices.
- It covers the new `sounds` value and checks that an unknown one is ignored.

## Not in this release

- The panel's browser and its settings; saved passwords.
- The phone link.
- Notifications and the Mac's side-panel preferences.
- Running sessions through Claude Code, Codex, Cursor, Grok or Antigravity.
- Installing the engine on a machine and running sessions there.
- Creating and editing bots on Windows.

These are tracked in `docs/ROADMAP.md`.
