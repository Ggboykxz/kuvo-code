# Kuvo Code 0.5.70 — the split is a card, and both conversations stay current

- **The split pane is the Mac's own card.** The pane carried a band of its own at the top
  — a session picker and a close button — and that band could be read as a second title
  bar, which the Mac never draws. It is the Mac's card now (`MainView.swift:733-754`): the
  very header the conversation's card has — the session's name over its project, the card's
  mark, the ring, and Swap and Close among the actions — over the same hairline, radius and
  fade, with its rows running under the header at the conversation's own 38 + 16 pt. There
  is no picker inside the pane.
- **A session opens beside another the Mac's way.** *Open Beside*, in the session's menu,
  opens the session beside the one in view (`SidebarView.swift:609`,
  `MainView.swift:757-775`); Swap exchanges the two places (MainView.swift:743-747). The
  split's conversation is a conversation like the other: while it is empty it asks the
  Mac's own question about its folder, and its working line shows while its run goes.
- **Both conversations follow the engine's events.** Every event is routed to each open
  conversation as the Mac routes it to the model of the session it names
  (`Workspace.swift:1458`, `models[id]`) — a conversation open beside the one in view keeps
  writing while you watch the other — and a turn that ends beside you is read back from the
  engine's own messages (`SessionModel.swift:640-655`).
- **A reconnection re-reads everything on screen.** At every connection the page re-reads
  the list, the conversation in view and the one beside it, as the Mac does
  (`AppModel.swift:448-459` → `Workspace.resync`, `Workspace.swift:1347-1359`): the events
  missed while the line was down are known again from the engine's own messages.

207 unit tests pass, `tsc --noEmit` is clean, the page builds, and the live page against
the real engine passes in Chromium — a second session is made, the split opens on the first
with its own header and rows, Swap exchanges them, the empty session asks its question
beside, and the split closes.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
