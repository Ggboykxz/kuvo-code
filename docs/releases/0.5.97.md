# Kuvo Code 0.5.97 — Worktrees

- **Worktrees, the Mac's way.** A session can run in its own copy of the project on a
  branch of its own, so its changes stay apart (`Workspace.swift:201-216`). The engine
  makes the worktree, the Windows client tracks it and can remove it; the branch starts
  with a name of its own.
- **A Worktrees page in Settings** (`GitSettings.swift:60-136`): where they are tracked,
  the list with each one's branch, project and folder, a button to show it in the
  Explorer, and one to remove it — with the Mac's warning that removing deletes the
  folder and anything in it that isn't committed.
- **The harness speaks the engine's worktree routes** (`POST /api/worktree`,
  `DELETE /api/worktree`, and `GET /api/location` for the project id), and `git branch`
  now takes the folder it runs in, so a worktree gets its branch where it lives.

316 unit tests pass — 256 in the port, 41 in the harness, 19 in the link bridge — with
`tsc --noEmit` clean, lint showing only the existing declaration warnings, the page
built, and the live Chromium engine suite green.

Windows 10/11, x64. The installer and the portable build are unsigned; Windows may warn on
first run.
