    Before you start

    Kuvo Code works entirely on this machine: the engine runs locally, its words go to the model provider you configured, and this harness collects nothing and reports nothing anywhere. Close the page and everything stops with it.

    From opencode's own settings

    MCP servers give the agent more tools, like a database, an issue tracker or your design files. A server on this machine runs a command; one on the web is a URL. To keep a key out of the settings file, write {env:NAME} to use one of your environment variables.

    Agents

    Modes are the agents you pick in the composer. Subagents are ones the agent hands part of a task to. New sessions use the model you picked last; the upper one is for when there's none. A small, fast model is enough for titles.

    Skills the Agent Can Use

    Loading…
    The agent loads a skill when a task calls for it. Skills in ~/.claude/skills and ~/.agents/skills, and in a project's .opencode/skills, are found on their own.

    Your Commands

    The engine's own

    Type / and a command's name at the start of a message to run it. What you type after the name fills in $ARGUMENTS; $1, $2 and so on are its words. !`command` puts in a command's output.
